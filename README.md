# languagestuday

每日英语 / 日语连续口语练习（Continuous Speaking Practice）

- **日本語モード**：連続スピーキング練習（話題カード ・ 面接対策 ・ 練習記録）
- **English モード**：生活英语话题练习 ・ 完整「生活美語」8000 句句子库（39 节 / 2851 句中英对照，支持逐句朗读与整节连读）

技术栈：Vite 5 + React 18，支持 GitHub Pages 静态部署与 PWA。

## 本地运行

```bash
npm install
npm run dev      # 开发
npm run build    # 构建到 dist/
npm run preview  # 预览
```
